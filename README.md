# 💼 Paymaster – Employee Payroll Management System

## 📌 About the Project

Paymaster is a web-based Employee Payroll Management System designed to simplify employee management and salary processing. It helps manage employee records, calculate salaries, generate monthly payroll records, and create printable payslips through a user-friendly dashboard.

## ✨ Features

* 📊 **Dashboard:** View employee statistics and payroll information.
* 👨‍💼 **Employee Management:** Add, view, update, search, and delete employee records.
* 💰 **Salary Calculation:** Calculate gross salary, deductions, overtime pay, and net salary.
* 🧾 **Payroll Management:** Generate and manage monthly payroll records.
* 📄 **Payslip Generation:** View and print employee payslips.
* 🗄️ **Database Integration:** Store employee and payroll information.
* 🌐 **User-Friendly Interface:** Simple and responsive web interface.
* 🔗 **REST API:** Manage employee and payroll data using Spring Boot endpoints.

## 🛠️ Technologies Used

* **Language:** Java 17
* **Backend:** Spring Boot
* **Frontend:** HTML, CSS, JavaScript
* **Database:** H2 Database
* **ORM:** Spring Data JPA
* **Build Tool:** Maven

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Java JDK 17 or later
* Maven
* A modern web browser

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd Paymaster
```

**3. Run the application**

```bash
mvn spring-boot:run
```

**4. Open the application**

Visit the following URL in your browser:

```text
http://localhost:8080
```

## 💰 Salary Calculation

The system demonstrates basic salary calculations using the following formulas:

* **Gross Salary** = Basic Salary + Allowances + Overtime Pay
* **Net Salary** = Gross Salary − Deductions − Estimated Tax

*Note: Actual tax rates and statutory deductions may vary. The calculations in this project are for demonstration purposes.*
